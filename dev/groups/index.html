Constructing Groups

Three constructors cover the common cases. Whatever you build is an AbstractFiniteGroup and supports the same accessors — name, order, class, inclass, mult — and the same character-table and representation machinery.

Crystallographic point groups

pointgroup returns one of the 32 crystallographic point groups, by Schoenflies symbol or by index 1:32:

using FiniteGroups

g = pointgroup("Oh")        # full octahedral group
(; group_name=name(g), group_order=order(g), num_classes=length(class(g)))
(group_name = "Oh", group_order = 48, num_classes = 10)

The valid symbols, in index order, are

C1, Ci, C2, Cs, C2h, D2, C2v, D2h, C4, S4, C4h, D4, C4v, D2d, D4h,
C3, C3i, D3, C3v, D3d, C6, C3h, C6h, D6, C6v, D3h, D6h, T, Th, O, Td, Oh

Point groups carry bundled reference data: the standard character table (used by charactertable unless you request another method), conventional irrep labels via repname, and the symmetry operations' rotation matrices via matrix (crystal-axis basis) and rotation (Cartesian). groupindex and operation recover a group's index and the list of operation symbols.

Symmetric and permutation groups

permutationgroup builds the symmetric group $S_n$ from an integer, or closes a set of generating permutations into a group. Permutations are written with cycles (disjoint-cycle notation) or permutation (an explicit $a \mapsto b$ table):

s4 = permutationgroup(4)        # the symmetric group S₄
Permutation group : S4
Group order       : 24
Classes           : 5
# the same group, generated from a transposition and a 4-cycle
g = permutationgroup([cycles((1, 2)), cycles((1, 2, 3, 4))], name="S4")
order(g)
24

From a multiplication table

For any finite group, hand FiniteGroup its multiplication table — a matrix whose entry [i, j] is the index of $g_i g_j$ — together with a name. Here is the cyclic group $C_4$, whose characters are genuinely complex:

multab = [1 2 3 4; 2 3 4 1; 3 4 1 2; 4 1 2 3]
c4 = FiniteGroup(multab, "C4")
charactertable(c4)
5×5 Matrix{Any}:
 ""        "1"         "2"         "3"         "4"
 "1"   1.0+0.0im   1.0+0.0im   1.0+0.0im   1.0+0.0im
 "2+"  1.0+0.0im   0.0+1.0im  -1.0+0.0im  -0.0-1.0im
 "3"   1.0+0.0im  -1.0+0.0im   1.0+0.0im  -1.0+0.0im
 "4-"  1.0+0.0im  -0.0-1.0im  -1.0+0.0im   0.0+1.0im

check_group validates that such a multiplication table really defines a group — a two-sided identity, associativity, and a permutation in every row and column. It takes the table itself:

check_group(multab)
true
