Getting Started

Installation

FiniteGroups is registered in the General registry, so it installs the usual way:

using Pkg
Pkg.add("FiniteGroups")

or, from the Pkg REPL (press ]):

pkg> add FiniteGroups

A first character table

using FiniteGroups

g = pointgroup("C3v")
charactertable(g)
4×4 Matrix{Any}:
 ""     "1"    "3₀₀₁⁺"    "m₁₁₀"
 "A1"  1      1          1
 "A2"  1      1         -1
 "E"   2     -1          0

The rows are the irreducible representations, labelled with their conventional Mulliken names, and the columns are the conjugacy classes. To get the plain numeric matrix, wrap the table in Matrix:

Matrix(charactertable(g))
3×3 Matrix{Int64}:
 1   1   1
 1   1  -1
 2  -1   0

Group properties

However a group was built, it answers the same small set of queries:

(; group_name=name(g), group_order=order(g),
   num_classes=length(class(g)), class_sizes=mult(g))
(group_name = "C3v", group_order = 6, num_classes = 3, class_sizes = [1, 2, 3])
  • name, order — the group's name and order $|G|$.
  • class — the conjugacy classes, each a vector of element indices.
  • inclass — the class index of a given element.
  • mult — the size of each conjugacy class.

Irreducible representations

charactertable gives the characters; irreps gives the representation matrices themselves. Each entry of the returned vector is one irrep — itself a vector of matrices, one matrix per group element.

rs = irreps(g)
[size(r[1], 1) for r in rs]      # the dimension of each irrep
3-element Vector{Int64}:
 1
 1
 2

So C₃ᵥ has two one-dimensional irreps and one two-dimensional irrep, and rs[3][k] is the $2 \times 2$ matrix representing the $k$-th group element in the E representation.
