Representations

Irreducible representations

irreps returns the irreducible matrix representations of a group: a vector with one entry per irrep, each entry itself a vector of matrices (one per group element). By default these are complex unitary representations.

using FiniteGroups

g = pointgroup("D3")
rs = irreps(g)
[size(r[1], 1) for r in rs]       # irrep dimensions — D₃ has irreps of dim 1, 1, 2
3-element Vector{Int64}:
 1
 1
 2

The matrices really are representations: rs[k][i] * rs[k][j] equals rs[k][m] whenever $g_i g_j = g_m$ in the group.

Real and complex realizations

Whether an irrep can be written with real matrices is governed by its Frobenius–Schur indicator: +1 for a real representation, -1 for a pseudo-real one, and 0 for a genuinely complex one. check_real_rep computes the indicator for a representation, real_rep realifies a single representation, and real_irreps returns all the irreps in real form:

ri = real_irreps(g)
[eltype(r[1]) for r in ri]        # real-valued matrices
3-element Vector{DataType}:
 Float64
 Float64
 Float64

The regular representation and projectors

regular_rep builds the (sparse, integer) regular representation; proj_operator forms the group-algebra projector $\sum_i c_i\, r_i$ from a character; and block_decomposition / proj_to_irrep decompose a given representation into its irreducible blocks. This is the machinery irreps itself uses to split the regular representation:

reg    = regular_rep(g)                 # |G| sparse permutation matrices
blocks = block_decomposition(reg, g)    # split into irreducible blocks

Projective and double-group representations

For spin-1/2 and double-group problems the package builds projective representations, where group multiplication is realized only up to a phase (factor system). cover_group forms the relevant central extension, proj_reps computes the projective irreps for a given factor system, chiral_proj_reps handles the chiral case, and check_proj_coeff verifies a factor system. The chiral routine takes a one-dimensional real irrep (a character with χ[1] == 1) as its phase factor:

ct = charactertable(g)
# use the one-dimensional A₂ irrep (row 2) as the chiral factor
rreps = chiral_proj_reps(g, Int.(ct[2, :]); R=true)

Manipulating representations

A few utilities round out the toolkit: transform_rep conjugates a representation by a change of basis, oplus forms the direct sum of representations, unitary_rep returns an equivalent unitary representation, and equivalent_transform finds the similarity transformation relating two equivalent representations.
